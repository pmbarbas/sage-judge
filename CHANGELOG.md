# Changelog

## 0.1.0 — experimental release

- Bounded finite signed-Horn reasoning with four proof postures and independent proof-witness checking.
- Source-bound reviewed premise admission and model-independent dependency coverage.
- Advisory review on unresolved coverage or model abstention; no execution authority.
- Fail-closed refusal of reachable dependencies beyond the qualified argument scope.
- Replayable decision records, offline API/CLI, synthetic examples and reproducible standalone tests.
- Curated release documentation and distribution identity. No natural-language semantic parser or scientific superiority claim.
